## Structure

Organised around one question — how an agentic system can combine evidence,
uncertainty and risk preference into decision support better than a
direction-only pipeline — and four subquestions:

- **RQ1 architecture** → §3 (what makes it agentic, seven observable properties), §6 Table 1
- **RQ2 target** → §6 Experiments A and B
- **RQ3 selective prediction** → §6 Experiment D (the headline result)
- **RQ4 decision support** → §6 Experiments E and F (matched-exposure control)

Experiment sequence: direction → volatility → calibration → abstention →
sizing → volatility targeting at scale → sealed prospective test.

Result hierarchy as agreed: abstention is the headline; portfolio Sharpe
superiority is not claimed anywhere.

Install explicitly if on-demand installation is disabled:
`miktex packages install apacite`.

## Provenance of the numbers

60 headline values in the manuscript were checked programmatically against
their source artefacts on 2026-08-25; all matched. The standing rule holds: if
a number is not in an artefact under `eval/results/` or `eval/forward/_runs/`,
it is not reproducible and must not be published.

### Corrections made against earlier drafts

The IEEE drafts in `../docs/` and `PAPER_V9_BLUEPRINT.md` disagreed with the
artefacts in six places. The artefacts won.

1. **Volatility targeting.** Blueprint said `t = -8.80`, winning on 47 of 196.
   `execution_policy.json` records `t = -8.47`, `p = 5.8e-15`, **50 of 196**.
2. **Drawdown reduction from targeting.** Blueprint said 3.6 pp; the artefact
   gives **4.3 pp** (−38.78% → −34.44%).
3. **QLIKE orientation.** An earlier version of this manuscript stated "larger
   is better". Both artefacts treat QLIKE as a **loss — lower is better**
   (`vol_forecast_h21.json` names `mean` as `best` at the lowest value).
4. **The volatility ranking is not stable.** The redesign run has EWMA best;
   the universe run has the **unconditional mean** best on QLIKE, with HAR-RV
   best on IC and MZ slope. Both are now reported, and §6.2 explains why the
   metrics disagree rather than picking the flattering run.
5. **Calibration.** The derived downside probability beats its base rate at
   only **one of three thresholds**, not generally. σ̂ is biased low by 11.0%.
6. **The forward test is no longer empty.** The blueprint says "80 sealed
   predictions, 0 scored". `forward/_runs/` now holds **240 sealed, 160
   scored** across five as-of dates — and the agentic arm (B) is *not* better
   than the numerical arm (A). This became Experiment G.

### Known reproducibility gap

**The predictability asymmetry table (§6.1 upper block: 196 equities, 43,512
observations, IC −0.0744 / +0.2489 / +0.5543 / −0.3199) has no machine-readable
artefact.** It exists only as prose in `docs/ANALYST_REDESIGN.md` and as
hardcoded constants in `eval/make_results_figure.py`. This is the paper's
central claim and a reviewer may ask for the code path. It should be
regenerated into `eval/results/` before submission.

## History

Content follows `../docs/PAPER_V9_BLUEPRINT.md`, restructured to the journal
brief. The IEEE-format drafts in `../docs/` (`FINDEC_v5`, `v5_final`,
`v6_fixed`, `v9`) remain for history; this directory is the live manuscript.

Changes in porting from the IEEE draft:

- Reframed for a finance readership: JEL codes, an efficiency-hypothesis null,
  and the power analysis promoted to its own section.
- Citations converted to APA author–year. The IEEE draft cited seven works and
  named a further dozen in prose without citing them; all are now cited.
- Three references (`chen2026smart`, `mantshimuli2026toward`, `sun2025financial`)
  were dropped. No `.bib` file ever existed in the repo, so their details could
  not be verified and nothing in the argument depended on them.
- Dropped per the brief: deployment-stack detail (FastAPI/Node/Next.js), the
  TSLA case study, and CPU-only operation as a contribution — the last is now
  one clause in §3.
